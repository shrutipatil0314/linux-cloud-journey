# Basic Commands Project

## Goal
Practice core Linux commands by building and organizing a mini office folder.

## Commands used
| Command | What it does |
|---|---|
| mkdir -p | Creates folders (and parents) |
| touch | Creates empty files |
| cp -r | Copies folders |
| mv | Moves or renames |
| grep | Searches inside files |
| find | Searches for files |
| rm | Deletes files |
