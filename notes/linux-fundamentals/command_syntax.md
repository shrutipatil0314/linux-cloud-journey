1. Linux commands generally follow the pattern: command [options] [arguments].

2. Options modify how a command behaves and usually start with a single hyphen (-) or double hyphen (-
-).


3. Multiple options can often be combined behind a single hyphen (e.g., using -la instead of -l -a).

4. Arguments specify the targets the command will act upon, such as files, directories, or users.
